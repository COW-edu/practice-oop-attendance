### 출석 확인

- [ ]  크루는 `nickname` 과 `datetime` 를 입력하여 출석부에 출석 여부를 등록할 수 있다.
- [ ]  크루는 출석 등록 후 자신의 기록을 확인할 수 있다.

### 출석 수정

- [ ]  크루는 `nickname` , `fixed_date` , `fixed_attendence_time` 을 입력하여 출석부에 출석 기록을 수정할 수 있다.
- [ ]  크루는 출석 수정 후 수정 전과 후의 기록을 확인할 수 있다.

### 크루별 출석 기록 확인

- [ ]  크루는 `nickname`을 입력해 전날까지의 출석 기록을 확인할 수 있다.
  - 출석 기록에는 날짜와 출석 시간, 지각 여부가 있고 출석, 지각, 결석 횟수가 나와있다.

### 제적 위험자  확인

- [ ]  크루는 전날까지의 기록을 바탕으로 제적 위험자를 조회할 수 있다.
  - 제적 위험자 목록에는 닉네임, 결석 / 지각 횟수, 경고/면담/제적 여부가 나와있다.
